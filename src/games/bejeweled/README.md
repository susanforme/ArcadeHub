# 宝石迷阵 / Bejeweled

Phaser 实现的经典三消模式，入口 `/#/game/bejeweled`。接入现有游戏大厅、
分数与最高分、暂停、音量、中英文、自动存档和离线资源打包。

- 8×8 棋盘，七种不同颜色和形状的宝石；初始棋盘没有现成三连，并保证存在可走步骤。
- 点击相邻两颗宝石、触屏滑动一格，或方向键移动光标后用 Enter / Space 依次选择。
  无法消除的交换会原路退回。只支持横、竖交换与消除。
- 三连消除，四连及 T / L 形交叉产生爆炸宝石，再次匹配时清除周围 3×3 区域；
  五连产生彩色宝石（hypercube），与邻居交换可清除该颜色。两颗彩色宝石交换清空棋盘。
  特殊宝石可相互引爆；爆炸击中彩色宝石时清除棋盘上数量最多的一种颜色。
- 宝石下落并补充新宝石，直到没有新的消除。每颗消除的宝石得 10 × 关卡 × 连锁轮数分。
  总分达到 `1000 × 关卡²` 后进入下一关，生成新棋盘并交替使用两张社区场景背景。
- 无倒计时、无步数限制；棋盘再也没有有效交换时结束，不自动洗牌。
- H / 提示按钮显示一个有效交换；闲置八秒自动提示。P / Esc 或平台按钮暂停。
  关卡完成及结束面板支持点击或 Enter / Space 继续、重玩。
- 只保存最近一次完整结算的棋盘。动画中退出或暂停时，不保存中间的空洞、位移或连锁分数；
  继续游戏回到该步交换之前。已完整结算的分数与棋盘一起保存。
