# Pang / Buster Bros. 打气球

原生 Phaser 单人游戏插件，使用 [Pang for Linux / pang-web](https://github.com/ray77/pang-web) 社区保留的经典像素美术与关卡布局，接入 ArcadeHub 的暂停、自动保存、继续、重开、音量、中英界面及虚拟手柄。

- 26 个连续关卡，保留上游的球体初始配置、平台位置、梯子和固定道具布置。
- 四级球体；每次击中大球分为两个更小的球，最小球击中后消失。
- 普通绳枪、双绳枪和可暂留在顶棚/固定平台的黏绳。
- 可破坏与固定平台、梯子、冻结时钟、护盾、炸药和加命道具。
- 三条初始生命、100 秒关卡时限、过关时间奖励与积分加命。
- 存档保留当前关卡的球体、绳枪、道具、已破坏平台、计时、生命和随机状态。

左右方向键或 A/D 移动，上下方向键或 W/S 爬梯，Space/Z/C 持续射击，Enter 开始/继续，P/Esc 暂停。触屏可按住射击并拖动方向移动/爬梯，也可使用平台虚拟手柄。

## 来源与差异

[assets/NOTICE.txt](./assets/NOTICE.txt) 记录上游版本、图像/声音来源和权利状态，[assets/COPYING](./assets/COPYING) 保留 GPL-2.0。关卡数据及本插件代码按 GPL-2.0 提供；社区项目的代码许可不等于原商业美术和音频已获独立商业授权。

这不是 ROM 模拟器。`levels.json` 转录了所选社区源码中实际存在的 1–26 关，不虚称原街机全 50 关；背景覆盖富士山至伦敦。物理、碰撞和时间步进重新实现，不保证与原版逐帧相同。当前没有双人、动物敌人、水果奖励、旅行地图动画或原版背景音乐。炸药将大球逐级分裂到最小球。
