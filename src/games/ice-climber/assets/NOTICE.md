# CC0 community artwork

All shipped Ice Climber images are derived from Kenney CC0 packs, recommended by
ASSETS.md. No Nintendo or IceClimberClone graphics are bundled.

- [Pixel Platformer](https://kenney.nl/assets/pixel-platformer): blue/pink helmeted characters, hammer (tile 69), snowman (tile 145), mushroom (tile 128). Original sheets: `Tilemap/tilemap-characters_packed.png` (24 px cells), `Tilemap/tilemap_packed.png` (18 px cells). License retained as LICENSE-pixel.txt.
- [Platformer Art Winter](https://kenney.nl/assets/platformer-art-winter), also [OpenGameArt](https://opengameart.org/content/platformer-art-winter): `Tiles/iceBlock.png`. License retained as LICENSE-winter.txt.
- [Platformer Art Deluxe](https://kenney.nl/assets/platformer-art-deluxe): `Base pack/Items/cloud1.png`, reused from the locally available pack also used by Fireboy & Watergirl. License retained as LICENSE-platformer.txt.

Author: Kenney Vleugels / Kenney.nl. The atlas arranges/resizes these images using
nearest-neighbor sampling. The cover composes the same assets with a plain text
title. Downloads and SHA-256 are recorded in SOURCE.json, retrieved 2026-10-15.

The original IceClimberClone sheet was investigated but excluded because it
explicitly prohibited distribution. Its source is retained only as a gameplay
reference link in the game README. This is an independent adaptation with a
CC0 winter visual theme, not original Nintendo artwork.
