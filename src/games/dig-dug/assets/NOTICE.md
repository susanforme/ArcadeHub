# Graphics provenance

- `sprites.png` is the unmodified transparent sprite sheet from [lazyleung/DigDugJS](https://github.com/lazyleung/DigDugJS/blob/master/digdugsprite.png), retrieved 2026-10-15. `SOURCE.json` records the tree and SHA-256.
- Original Dig Dug characters, logo and graphics belong to Namco / Bandai Namco. The community repository has no explicit license granting commercial or general redistribution of these graphics. They are **not CC0 or MIT**. This integration makes no claim that community hosting grants such rights.
- `cover.png` is a composition of crops from that sheet, so the same original-art rights apply.
- No upstream game code, music or ROM is included. Simulation and generated maps are new TypeScript code.
- ASSETS.md's Kenney/OpenGameArt alternatives were considered; original artwork was preferred as explicitly requested. A separately cleared replacement pack is needed if unrestricted commercial redistribution is required.
