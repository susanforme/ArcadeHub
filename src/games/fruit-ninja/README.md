# 水果忍者

经典模式：鼠标按住拖动或触屏划动切水果，每颗 1 分；140ms 内连续切中三颗获得额外 3 分，继续连切每颗再奖励 1 分。漏掉三颗水果或切中炸弹结束。果阵数量与速度逐渐增加，前两阵没有炸弹。

划开标题页西瓜、点击圆环或按 Enter / Space 开始。P / Esc 或平台按钮暂停；失焦自动暂停。平台重开按钮可直接重置；结束页按钮和 Enter / Space 返回开始画面。

通过 SessionScene 接入分数、最高分、自动存档及继续游戏；存档保留场上水果位置和速度，不恢复划动轨迹。仅鼠标悬停或点击水果不会得分。所有物理、轨迹、粒子在暂停期间停止。

素材按 ASSETS.md 的 GitHub 社区渠道查找，使用 ChineseDron/fruit-ninja 中的经典风格图片及音效，文件来源、固定版本及授权状态见 [NOTICE](assets/NOTICE.txt)。社区仓库没有明确授权声明；这些资源不能宣称为已获商业再分发授权的开源资源。

游戏采用独立实现的弹道和碰撞逻辑，没有运行社区旧版引擎。不是官方发行版本，未引入商店、多种模式或官方关卡。

入口：`/#/game/fruit-ninja`。逻辑验证：`bun run test fruit-ninja`。
