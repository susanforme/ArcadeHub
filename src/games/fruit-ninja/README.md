# 水果忍者

经典模式：鼠标按住拖动或触屏划动切水果，每颗 1 分。同一次划动切中三颗及以上，获得与连击水果数相同的额外分数，例如三颗共 6 分、四颗共 8 分；随机暴击每颗额外加 10 分，并有独立提示。每根手指独立计算连击，抬起、反向或停止移动超过 300ms 后重新计数，连续移动穿过空白区域不会因没有切中水果而断连。

开局三条生命，漏切一颗扣一条，耗尽后结束；分数每跨过一个 100 分的整数倍恢复一条，最多三条。满生命时不储存恢复次数，连击与暴击跨越分数门槛也会触发恢复。右上保留原版叉号素材，并显示剩余生命；左上显示恢复规则或距下次恢复所需分数。切中炸弹仍立即结束。

果阵的数量、间距、位置和间隔有随机变化，数量、速度和出现频率随进程提高；前两阵没有炸弹。生成时保留完整阵列的屏幕边距，避免边缘裁剪把多颗水果或炸弹挤在同一点，并限制场上对象总数。

划开标题页西瓜、点击圆环或按 Enter / Space 开始。P / Esc 或平台按钮暂停；失焦自动暂停。平台重开按钮可直接重置；结束页按钮和 Enter / Space 返回开始画面。

通过 SessionScene 接入分数、最高分、自动存档及继续游戏；兼容原有 version 1 存档，保留分数、剩余生命、场上水果位置和速度，不恢复划动轨迹或手势连击。恢复门槛由分数计算，继续游戏不会重复领取生命。仅鼠标悬停或点击水果不会得分。所有物理、轨迹、粒子在暂停期间停止。

素材按 ASSETS.md 的 GitHub 社区渠道查找，使用 ChineseDron/fruit-ninja 中的经典风格图片及音效，文件来源、固定版本及授权状态见 [NOTICE](assets/NOTICE.txt)。社区仓库没有明确授权声明；这些资源不能宣称为已获商业再分发授权的开源资源。

游戏采用独立实现的弹道和碰撞逻辑，没有运行社区旧版引擎。不是官方发行版本，未引入商店、多种模式或官方关卡。

规则参考 Halfbrick 的[官方玩法说明](https://halfbrick.helpshift.com/hc/en/38-super-fruit-ninja/faq/1047-what-are-the-game-modes/)与[官方入门指南](https://www.halfbrick.com/blog/the-ultimate-beginners-guide-to-fruit-ninja)。原版未公开精确暴击概率、手势容差和完整出果参数，本实现采用 5% 暴击概率、300ms 停顿容差以及独立调校的出果参数，不能视为逐帧复刻。

入口：`/#/game/fruit-ninja`。逻辑验证：`bun run test fruit-ninja`。
