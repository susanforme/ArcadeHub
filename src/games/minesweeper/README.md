# Minesweeper

Phaser plugin with community 21×21 pixel sprites, Kenney digital sounds, and
classic community difficulty presets. See assets/NOTICE.txt for sources and licenses.

- Beginner: 9×9 / 10 mines; Intermediate: 16×16 / 40; Expert: 30×16 / 99.
- First reveal and its eight neighbors are safe. Blank cells flood open.
- Reveal every non-mine cell to win. Flags are optional and can be wrong.
- Click/tap to reveal; right-click, hold a touch for 450 ms, or use flag mode to flag.
- Click a revealed number to open neighbors when adjacent flags match its number.
- Drag to pan large boards, and toggle Fit board / Zoom in to inspect the whole field.
- Arrow keys select a cell; Enter/Space reveals, F flags, R restarts, Z zooms, P/Esc pauses.
- Active boards resume through the platform save system; pause stops the clock.
- Classic randomized minefields can require guessing. No additional hand-authored levels.
