# T-Rex Runner resources

Source: https://github.com/wayou/t-rex-runner
Commit: 5455bfa408ec6b707c7300ff194b7390733a766d

The original 2x Chromium atlas is copied unchanged. Three Ogg effects (press, hit, reached) are extracted from the embedded audio in the repository index.html without transcoding. Frame coordinates, collision shapes and gameplay tuning are adapted from index.js. cover.svg composes the supplied atlas into a lobby cover.
