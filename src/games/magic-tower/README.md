# 魔塔 / Magic Tower

ArcadeHub 原生的十二层魔塔战役。经典三色钥匙、固定数值战斗、攻击/防御宝石、药水、金币商店、上下楼探索、怪物损伤预览。

- 方向键/WASD 或触屏方向盘移动，点击相邻格移动，点击怪物查看属性。
- Z 撤销最近 128 步；R 恢复本次进入楼层时的完整快照；B 切换怪物损伤。
- 商店位于每层左下角，邻接互动后可购买攻击、防御或生命。
- 不允许执行无法生还的战斗；怪物最后一击不反击。
- SessionScene 统一暂停/重开/IndexedDB 自动存档。地图中的物品、门、怪物、钥匙、历史和楼层入口快照一起保存，并验证所有嵌套结构。
- 十二层为本项目独立设计，并非原版 21/24/50 层搬运。地图有三种基础布局；怪物逐层增强。测试通过公开移动规则完成整座塔，无调属性、无商店加成，证明至少一条可行路线。撤销和楼层重试用于纠正资源分配。
