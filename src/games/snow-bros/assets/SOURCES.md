The supplied files are stored unchanged. Phaser removes the separator colour
`#18e020` in memory and selects sprite frames from the original sheets. The four
backgrounds are the four leftmost 256×208 cells in the first row of `levels.png`.
`cover.svg` embeds the unchanged level sheet and adds an ArcadeHub title treatment;
the underlying artwork retains the same original-game rights.

The source catalogue documents extraction from the arcade graphics data. Its
community availability must not be confused with a licence from the rights owner.
Before a public/commercial release, obtain the relevant artwork permission or
replace these original graphics with appropriately licensed alternatives.

Implementation and stage rules in `../logic.ts` are new code for ArcadeHub. This
is a four-stage single-player interpretation, not a complete emulation of all
50 original stages. Audio reuses ArcadeHub's existing shared feedback sounds.
