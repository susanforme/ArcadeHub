The Phaser/TypeScript gameplay is a new implementation. Selected Unity sprite
rectangles were extracted into a PNG atlas without redrawing, preserving GIF
transparency. Background fragments were extracted from Unity sprite metadata.
Original audio clips are included unchanged. SOURCE.json records source paths,
revision and SHA-256 of the original files; import-metal-slug.py reproduces the
asset conversion. Original README is preserved in UPSTREAM-README.md.

The port rearranges stage layouts and encounters. It does not run the Unity
scenes, Animator controllers, Cinemachine tracks, physics or C# event scripts.
