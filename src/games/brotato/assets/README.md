# Community assets

Sources were selected from the root ASSETS.md; files are imported locally.

- **Kenney Monster Builder Pack** (CC0): https://kenney.nl/assets/monster-builder-pack
  Potato/enemy PNGs compose the upstream oval bodies, legs, eyes and mouths.
  Potato uses `body_yellowC`, `leg_yellowA`, `eye_cute_dark`, and
  `mouth_closed_happy`; its yellow body is tinted brown. Other monsters use
  green/red/dark/blue body parts. Parts and weapon/icon transparent margins are trimmed and resized, not repainted.
- **Kenney Scribble Dungeons** (CC0): https://kenney.nl/assets/scribble-dungeons
  Original dagger, spear, staff, shield, tree and crate PNGs.
- **Kenney Top-down Shooter** (CC0): https://kenney.nl/assets/top-down-shooter
  `tile_05` dirt floor; `weapon_gun`, `weapon_machine`, `weapon_silencer` stand in for the three guns.
  Shotgun uses the long gun illustration; combat fires spread pellets.
- **Kenney Digital Audio** (CC0): https://kenney.nl/assets/digital-audio
  `laser1` → shoot; `lowDown` → hit; `pepSound1` → collect;
  `powerUp1` → level/shop/wave clear. Original OGG files.
- **Mining Pixel Game Asset**, acdrnx (CC0): https://opengameart.org/content/mining-pixel-game-asset
  Diamond/material, power drink/coffee, bag/harvesting and lens/crit images
  reuse this repository's Gold Miner imports. Upstream notice is retained.
- **Kenney Platformer Art Candy** (CC0): https://kenney.nl/assets/platformer-art-candy
  `lollipopWhiteRed`, from the existing Cut the Rope imports, is food/regen.
- **Heart Bottle**, **Lorc**, **CC BY 3.0**:
  https://game-icons.net/1x1/lorc/heart-bottle.html
  https://creativecommons.org/licenses/by/3.0/
  White transparent SVG; added an accessibility title. Credited on the ready
  screen and here. The scene tints images as needed.

`SOURCE.json` records selected source filenames and SHA-256 hashes, including
parts used in character composition. Original Kenney licenses are preserved.
`cover.png` composes the same community character and weapon PNGs.
No original commercial Brotato artwork, audio or code is included.
