The original math, Hex, Block, checking, wavegen, update, timer and text
code and original icon are retained. The game artwork is the original
procedural vector artwork, not replacement text or placeholder graphics.
ArcadeHub changes: module-local engine, deterministic 60 Hz simulation,
platform input/pause/storage, structured data-only checkpoints, translated HUD.
Removed original DOM/jQuery/analytics/advertisements/social posting/network score
reporting and executable-function save serialization. Source is distributed at
https://github.com/susanforme/ArcadeHub together with this adaptation.
